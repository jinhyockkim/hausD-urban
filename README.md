# 하우스디어반 동네 한바퀴 🖍️

대전 도룡동 **하우스디어반 상가(1층 + 2층)**를 파스텔 크레파스 톤의 지도로
그리고, 가게마다 방문 후기(별점 1~5 + 사진 + 한 줄 평)를 남길 수 있는 앱입니다.
지도는 현장 INFORMATION 안내판 사진을 기준으로 실제 배치(왼쪽 F·E·D /
오른쪽 A·B·C, 가운데 중앙로)를 따라 그렸습니다.

## 실행 방법

정적 파일이라 그냥 열면 됩니다.

```bash
# 아무 정적 서버로 열기 (사진 첨부 등 모든 기능 동작)
npx http-server -p 8642 .
# → http://localhost:8642
```

`index.html`을 더블클릭해서 파일로 열어도 동작합니다(폰트만 인터넷 필요).

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (지도 렌더링, 리뷰 시트, 랭킹/피드 탭, 편집 모드) |
| `data.js` | **상가 데이터** — 층(`FLOORS`)·동 격자 배치, 입주 업체(`TENANTS`) 목록 |

### 데이터 구조 (v2)

- 각 **동(building)** 은 `cols × rows` 격자입니다 (`cw`/`ch`는 칸 하나의 픽셀 크기).
- 각 **업체(tenant)** 는 `blocks` 배열로 자기 구역을 가집니다:
  `{ b:'F', r:[열, 행, 열칸수, 행칸수] }`
- 한 업체가 여러 구역(다른 동 포함)을 쓰면 blocks를 여러 개 넣으면 됩니다
  — 예: 2층 너티차일드 키즈카페는 G동 전체 + F동 블록. 이름은 가장 큰
  구역에만 표시됩니다.

## ✏️ 편집 모드 — 전부 화면에서 직접

안내판 사진을 판독해 데이터를 만들었기 때문에 일부 상호가 부정확하거나
`미확인`(점선 칸)으로 들어가 있습니다. **수정은 전부 지도 위에서 직접 합니다
— data.js를 손으로 고칠 필요가 없어요.**

1. 우측 상단 **✏️ 편집** 버튼을 켜고, 지도에서 가게를 탭하면 **선택**됨
   (주황 점선 테두리 + 도구 막대)
2. 선택된 가게를:
   - **드래그 → 위치 이동** (동 안의 격자에 착착 스냅)
   - **모서리 ⬤ 손잡이 드래그 → 크기 조절** (가로/세로 칸 수 변경)
   - **✏️ 이름·종류** 버튼 → 상호명·카테고리 수정
   - **➕ 칸 추가** → 같은 가게에 구역 하나 더 (L자 모양, 떨어진 구역 등)
   - **🗑 칸 빼기 / 가게 삭제**
3. **➕ 새 가게** (상단 막대) → 빈 칸에 새 가게가 생기고 바로 이름 입력
   — 신규 입점 가게 대응
4. 모든 수정은 브라우저(localStorage)에 즉시 저장. 끝나면
   **📥 data.js 내보내기**로 파일을 받아 프로젝트 폴더의 `data.js`에
   덮어쓰면 영구 반영 (다른 기기/브라우저에서도 같은 데이터 사용 가능)
   - **↩️ 파일 데이터로 초기화**: 브라우저 편집본을 버리고 `data.js`로 복원

참고: 블록끼리 겹치는 것을 막지 않으므로(편집 중 자유도를 위해),
드래그 후 다른 가게와 겹쳐 보이면 살짝 옮겨 주세요. 동 자체의 격자
크기를 바꾸는 것(`FLOORS` → `buildings`의 `cols`/`rows`)만 파일 수정이
필요합니다.

## 현재 구현된 기능

- 🖍️ **크레파스 지도**: SVG `feTurbulence` 변위 필터 + 손그림 흔들림이 들어간
  파스텔 톤 블록. 동별 색상 구분(A주황·B보라·C분홍·D파랑·E노랑·F초록 등)
- 🏢 **1층/2층 전환**: 층마다 동 구성이 다름 (2층은 H·G동 + 너티차일드 키즈카페)
- 🏪 **업체 단위 병합**: 여러 칸·여러 동을 쓰는 가게도 분절 없이 한 가게로 취급
- ⭐ **리뷰**: 별점 1~5 + 한 줄 평 + 사진 최대 4장(자동 리사이즈/압축 후 저장)
- 🗂 **검색 / 카테고리 필터**: 식당·카페·술집·디저트·편의점 등으로 지도 하이라이트
- 🥇 **랭킹 탭**: 내 별점 평균순 정렬
- 📰 **피드 탭**: 시간순 방문 기록 타임라인
- 🐾 **방문 스탬프**: 리뷰 남긴 가게 수 카운트 (게이미피케이션 씨앗)
- 🖍️ **가본 곳 표시**: 리뷰 남긴 가게는 진한 크레파스 색 + 굵은 테두리 +
  모서리에 🐾 도장이 찍힘. 필터의 "🐾 가본 곳" 칩으로 내 가게만 모아보기
- ✏️ **편집 모드**: 상호명·카테고리는 물론 칸의 위치·크기까지 지도에서
  드래그로 직접 수정 (새 가게 추가/삭제 포함), 끝나면 `data.js`로 내보내기
- 💾 저장은 브라우저 `localStorage` (서버 없음 = 개인 기록장 모드)

# 아이폰 앱으로 가는 3단계 로드맵

### 1단계 — 지금 바로: PWA (홈 화면에 추가)
이미 `apple-mobile-web-app-*` 메타 태그가 들어 있어서, 아이폰 Safari에서
**공유 → 홈 화면에 추가**를 하면 주소창 없는 standalone 앱처럼 실행됩니다.
비용 0원, 심사 없음. 단 데이터가 기기 안에만 남습니다.

### 1.5단계 — 내 폰에 직접 설치 (앱스토어 X, 서버 X): `ios/` 폴더
무료 Apple ID + Xcode로 본인 아이폰에 직접 설치하는 WKWebView 래퍼를
준비해 뒀습니다. 웹앱이 앱 안에 내장되어 인터넷이 전혀 필요 없습니다.
자세한 단계는 [ios/README-iOS.md](ios/README-iOS.md) 참고.
(무료 계정은 서명이 7일마다 만료 — Mac에서 Run 한 번이면 갱신, 데이터 유지)

### 2단계 — 가벼운 네이티브: Capacitor 래핑
지금 코드를 그대로 [Capacitor](https://capacitorjs.com)로 감싸면 App Store에
올릴 수 있는 iOS 앱이 됩니다.
- `@capacitor/camera` → 카메라 직접 호출, `@capacitor/geolocation` → 방문 인증
- 저장소를 localStorage → SQLite(`@capacitor-community/sqlite`)로 교체
- 웹 코드 1벌로 iOS + Android 동시 대응

### 3단계 — 제대로: SwiftUI 네이티브 + 백엔드
여러 사람이 함께 쓰는 서비스로 키울 때:
- **클라이언트**: SwiftUI. 지도는 SVG 좌표를 그대로 `Canvas`/`Shape`로 이식
  (크레파스 질감은 텍스처 이미지 오버레이가 더 쉬움)
- **백엔드**: Supabase 또는 Firebase
  - `tenants`(상가), `reviews`(별점/텍스트), Storage(사진), Auth(애플 로그인)
- **오프라인 우선**: 현장에서 쓰고 나중에 동기화 (SwiftData + 백그라운드 업로드)

# 유사 앱 벤치마킹 — 추가하면 좋은 기능 설계

네이버 지도/플레이스, 캐치테이블, (구)망고플레이트, 스마트오더 앱들이 공통으로
가진 기능 중 이 앱의 "동네 한 바퀴" 컨셉에 맞는 것들:

| 기능 | 설명 | 난이도 |
|---|---|---|
| 🏷 **태그 리뷰** | 별점 외에 "재방문각 / 가성비 / 분위기 / 혼밥OK" 같은 원터치 태그 | ★ |
| ❤️ **즐겨찾기 & 가고싶다** | 위시리스트 → 지도에 하트 표시 | ★ |
| 🗓 **영업시간·휴무일** | data.js에 필드 추가, 지도에서 "지금 영업 중"만 필터 | ★ |
| 🍜 **대표 메뉴 & 가격** | 가게 시트에 메뉴판 사진/리스트 섹션 | ★★ |
| 🐾 **스탬프 투어 / 배지** | "A동 정복!", "카페 5곳 클리어" 같은 수집 배지 — 단지 상가라 특히 잘 어울림 | ★★ |
| 📍 **방문 인증(GPS)** | 실제로 그 위치에 갔을 때만 리뷰 작성 허용 → 리뷰 신뢰도 확보 | ★★ |
| 👥 **친구와 공유** | 내 지도(별점 칠해진 크레파스 맵)를 이미지로 내보내 공유 — 바이럴 포인트 | ★★ |
| 💬 **사장님 답글 / 소식** | 입점 업체 계정이 신메뉴·휴무 공지 → 동네 커뮤니티화 | ★★★ |
| ⏳ **웨이팅 현황** | 캐치테이블식 실시간 줄서기 — 점심시간 연구단지 수요와 잘 맞음 | ★★★ |
| 🔔 **신규 입점/폐점 알림** | `미확인` 호실이 채워지면 푸시 알림 | ★★★ |
| 📊 **나의 동네 통계** | "이번 달 12곳 방문, 최애는 카페" 연말결산(Wrapped) 스타일 리포트 | ★★ |

**추천 우선순위**: 태그 리뷰 → 즐겨찾기 → 스탬프 배지 → 지도 이미지 공유.
넷 다 서버 없이 지금 구조(localStorage)에서 바로 얹을 수 있고,
"내가 칠해가는 동네 지도"라는 컨셉을 가장 강화해 주는 기능들입니다.
